# SnapGene DNA Plasmid Maps

SnapGene `.dna` copies of the 10 LiSPER pET-28a(+) expression constructs.

Use these files for SnapGene editing, visual map inspection, and strain/construct metadata review. The matching text-source GenBank files are stored in `../genbank/`.

## Metadata QC

All 10 files have been inspected as SnapGene DNA files. Each file now carries:

| Field | Value |
|---|---|
| `Organism` | `Escherichia coli` |
| `TransformedInto` | `BL21(DE3)` |
| Source feature strain | `BL21(DE3)` |

Small color differences from the GenBank view are expected because SnapGene `.dna` files store display state, enzyme visibility, and feature styling in addition to sequence annotations.
