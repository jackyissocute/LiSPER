# GenBank Plasmid Maps

Annotated circular GenBank files for the 10 LiSPER pET-28a(+) expression constructs.

These `.gb` files are the text-source plasmid maps used for version control and downstream conversion. Each construct is annotated with `BL21(DE3)` as the bacterial transformation/expression strain.

The matching SnapGene binary files are stored separately in `../snapgene_dna/`.

## Metadata QC

All 10 GenBank files have:

| Field | Value |
|---|---|
| `SOURCE` | `Escherichia coli BL21(DE3)` |
| `ORGANISM` | `Escherichia coli BL21(DE3)` |
| Source feature `/strain` | `BL21(DE3)` |
| `COMMENT` | `Bacterial transformation strain: BL21(DE3).` |
