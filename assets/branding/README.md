# LiSPER branding assets

_Official visual assets for repository presentation, project documents, and scientific communication._

## Asset map

| Folder | Contents | Intended use |
|---|---|---|
| `banners/` | Wide project banner graphics | README header, presentation cover slides, project landing pages |
| `logos/` | Full logo and logo-lockup variants | README title area, reports, manuscript-adjacent material |
| `icons/` | Standalone icon marks | Favicons, small badges, slide corners, compact layouts |

## Visual identity

LiSPER uses a dark scientific-technology visual language: deep navy backgrounds, electric cyan/blue highlights, glowing Li+ coordination, flexible peptide ribbon motifs, and rejected Na+ ions. The brand should feel precise, molecular, sustainable, and computationally modern.
