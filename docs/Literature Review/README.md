# Literature Review

This folder stores the literature background for the LiSPER design logic.

- `IDP/`: intrinsically disordered protein literature and metal-binding background.
- `LBP/`: lithium-binding peptide/protein literature, including reports of GPGNP/GPGDP-related lithium recovery systems.

Use these sources to support candidate design rationale, simulation assumptions, and eventual manuscript background.
