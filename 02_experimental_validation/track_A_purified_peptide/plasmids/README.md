# Plasmids

This folder contains LiSPER expression-plasmid design files, vector maps, vendor-ready construct packages, and archived historical designs.

## Current Vendor-Ready Set

Use the SUMO fusion designs in:

| Path | Purpose |
|---|---|
| `vendor_ready_SUMO/` | Current recommended His6-SUMO-LiSPER plasmid package for vendor review/submission |
| `vendor_ready_SUMO/restriction_cloning_insert_order/` | Current vendor-ordering insert package for original pET-28a(+) backbone restriction cloning |
| `vendor_ready_SUMO/genbank/` | Annotated SnapGene-compatible GenBank plasmid maps for all 10 constructs |
| `vendor_ready_SUMO/insert_sequences/` | FASTA files for synthetic ORFs, translated fusion proteins, and liberated native peptides |
| `vendor_ready_SUMO/SUMO_construct_summary_table.csv` | Construct summary with peptide sequence, fusion MW, native peptide MW, predicted fusion sequence, and post-cleavage peptide |
| `vendor_ready_SUMO/SUMO_plasmid_order_table.csv` | Vendor-facing construct table |
| `vendor_ready_SUMO/SUMO_LiSPER_vendor_submission_report.md` | Final wet-lab/vendor submission report |

Current expression architecture:

```text
T7 promoter -> RBS -> His6 -> Smt3 SUMO -> LiSPER peptide -> STOP
```

The LiSPER peptide starts immediately after the SUMO C-terminal `GG`, so SUMO protease cleavage is designed to release the exact native peptide with no residual His-tag, T7 tag, linker, thrombin remnant, or vector-derived residues.

For standard vendor ordering, use the revised restriction-cloning insert package. It keeps the original pET-28a(+) backbone and asks the vendor to synthesize each complete `His6-SUMO-LiSPER-STOP` ORF insert for NdeI/XhoI cloning into the original MCS.

## Reproducibility

The current SUMO package is generated by:

```bash
python 06_project_operations/scripts/design_pet28a_SUMO_lisper_plasmids.py
```

The generator reads candidate peptide sequences from `01_computational_discovery/sequences/candidates.tsv`, uses the local `02_experimental_validation/track_A_purified_peptide/plasmids/vector_maps/pET28a_plus.dna` vector map, and writes the current package to `02_experimental_validation/track_A_purified_peptide/plasmids/vendor_ready_SUMO/`.

The restriction-cloning insert order package is generated by:

```bash
python 06_project_operations/scripts/generate_revised_SUMO_restriction_order.py
```

## Submission Guidance

For vendor discussion, start with:

1. `vendor_ready_SUMO/restriction_cloning_insert_order/revised_vendor_instructions.txt`
2. `vendor_ready_SUMO/restriction_cloning_insert_order/revised_vendor_order_table.csv`
3. `vendor_ready_SUMO/restriction_cloning_insert_order/restriction_site_QC_report.csv`

Ask the vendor to use the original pET-28a(+) backbone and clone each synthesized insert into the original MCS using NdeI/XhoI. The 5' NdeI site contains the ORF start codon; do not duplicate the ATG after NdeI. Ask the vendor to sequence-verify the full insert and both junctions and return plasmid DNA, final maps, full sequences, and Sanger reports.
