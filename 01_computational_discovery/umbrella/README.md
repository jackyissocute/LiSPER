# Umbrella sampling

The paired LiCl/NaCl umbrella campaign is complete for all eight candidates: 16 pulls, 480 equilibration windows, and 480 production windows. The [2026-07-25 archive](analysis_archive_20260725/README.md) documents local coverage, source checks, WHAM products, and any large files retained only on remote or cold storage.

Each campaign started from a selected production-MD representative and a locked paired site. The historical [preflight runbook](PREFLIGHT_RUNBOOK.md), [window plan](WINDOW_ASSIGNMENT_PLAN.md), and [campaign status](remote_runs_umbrella_sampling_status.md) record how the work was run; their operational instructions are not a claim that more jobs are queued.

The resulting [PMF analysis](../pmf/README.md) reports radially corrected, endpoint-referenced within-protocol Li⁺/Na⁺ comparisons. Window counts are sampling coverage, not independent experimental replicates. Diagnostics and incomplete local trajectory coverage remain visible in the archive.
