# 06 Shared

This area contains cross-project resources that support all LiSPER stages.

| Folder | Purpose |
|---|---|
| `docs/` | Repository guide, design rationale, workflow notes, and reorganization reports. |
| `scripts/` | Reusable project scripts. |
| `inbox/` | Temporary drop zone for files that need classification. |

The inbox should usually be empty after files are moved into the appropriate stage folder.
